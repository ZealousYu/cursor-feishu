# 飞书文档本地同步目录

Agent 可将飞书云文档下载保存到此目录（Markdown 格式）。

## 用法示例

在 Cursor Agent 中说：

> 把这个飞书文档保存到 cursor-feishu/feishu-sync/产品方案.md：https://xxx.feishu.cn/docx/xxxxxx

> 读取 cursor-feishu/feishu-sync/产品方案.md，更新后同步回飞书文档 doxcnxxx
